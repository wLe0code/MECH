# Dependencias OPCIONALES para la visión (detección de usuarios con la C930e).
#
# Se instalan aparte a propósito: si fallan, NO deben tumbar la instalación
# del resto del robot. El backend importa cv2/mediapipe de forma perezosa, así
# que sin estos paquetes el server arranca igual (con la visión deshabilitada).
#
# Hay DOS backends de detección de rostros; el código elige el mejor que haya:
#
#   1. OpenCV (obligatorio para cualquier visión). Trae un detector Haar
#      integrado que funciona en CUALQUIER Python donde OpenCV instale,
#      incluido Python 3.13. Detecta caras frontales a distancia media —
#      suficiente para un stand. Con solo esto la visión YA funciona:
#
#          pip install opencv-python-headless
#
#   2. MediaPipe (opcional, mejora la detección: full-range ~5 m, caras de
#      perfil). ⚠️ mediapipe SOLO tiene wheels para Python 3.11 y 3.12
#      (NO 3.13). Si tu .venv es 3.13 y quieres mediapipe, recréalo:
#          python3.11 -m venv .venv && source .venv/bin/activate
#          pip install -r backend/requirements.txt
#
# Instalar ambos (en Python 3.11/3.12):
#   pip install -r backend/requirements-vision.txt

# Backend de visión mínimo (funciona en Python 3.13).
# OJO: fijado a la serie 4.x — OpenCV 5 eliminó cv2.CascadeClassifier,
# que es lo que usa el detector Haar de respaldo en vision.py.
opencv-python-headless>=4.9.0,<5

# Mejora opcional — solo instala en Python 3.11/3.12.
mediapipe>=0.10.14
